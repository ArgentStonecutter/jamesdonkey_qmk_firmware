# JamesDonkey J4

![JamesDonkey J4]

A customizable TKL keyboard.

* Keyboard Maintainer: [James Donkey](https://github.com/james-donkey)
* Hardware Supported: JamesDonkey J4
* Hardware Availability: [JamesDonkey J4 QMK/VIA Wireless Custom Mechanical Keyboard]

Make example for this keyboard (after setting up your build environment):

    make james_donkey/j4:via
    make james_donkey/j4:default

Flashing example for this keyboard:

    make james_donkey/j4:via:flash
    make james_donkey/j4:default:flash

**Reset Key**: Toggle mode switch to "Cable", hold down the *Esc* key or reset button underneath space bar while connecting the USB cable,

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
